
(Following does not apply to just habit tracker app, but any app that collects data)

### Whatever you are collectiong, must be relevant
-   Immediately after you have created it
-   After some time, when you have a lot of data, still it should be relevant

-   search should be easy
-   if you have a lot of data, some stats should be deduced (so that user can act on his path)

-   The data should be available even after a long time.
-   If user were using older system, there should be a way people can migrate to yours
-   The software should be beautiful
-   (Optional) Involve community, so user can ask / answer any related question and that will help him 
- (Optional) Allow people to share their blog posts
-   (Optional) Post suggestions

  

### Involve feedbacks

-   Encourage good behaviours and discourage bad behaviours (like [keybr.com](http://keybr.com))
-   If user has been consistent, show him the graph (as [github.com](http://github.com) does)
- Allow people to share the graph on social media.
-   If user has not been consistent, encourage him in some way
